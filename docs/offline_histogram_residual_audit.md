# Private nonlinear quote audit

This audit replaces one signed-target linear estimator with one fixed shallow histogram-tree estimator. It keeps the private source cohort, train-only feature scaling, available-label cutoff, physical timed-bid target and execution rules unchanged.

The configuration binds an immutable parent protocol and a separate base data/execution protocol. Six prior modules remain byte-identical. Before a new model is constructed or fitted, the runner verifies source/code identity, full feature and training-member hashes, known/unknown cohort identities, persistence metrics, cached control candidates and every complete control ledger fingerprint. Control metrics are an audited, hash-bound cache; the control model is not refitted or fully rescored.

The private configuration uses one bounded XZ stream inside base64, with an exact digest of expanded JSON, an expansion bound and a decoder memory limit. The workflow pins the numeric dependency versions and the runner verifies their loaded versions and the estimator's complete effective parameters.

Native JSON tree artifacts preserve training-only scaling and bins, baseline, complete node arrays and iteration order. Leaf values already include learning-rate shrinkage. Safe explicit tags cover permitted infinite thresholds or gains; invalid nonfinite model values are rejected. A separately frozen reader reconstructs predictions through tree traversal without loading pickle or fitting an estimator. Synthetic producer-to-reader contracts check the actual saved schema.

Prediction errors, candidate cardinality, forced exits, retained inventory, and same-ledger cash growth are separate outcomes. Unknown targets remain scored. Insufficient exits retain inventory and cannot be treated as a realized zero-value loss. Diagnostic paths cannot be concatenated into a growing ten-trade sequence. The research assumptions are not authenticated venue constraints, fills or account cash receipts.

Only ciphertext is uploaded and permanently published. The ciphertext artifact is retained before journal publication so recovery is idempotent; runner plaintext is then removed. This workflow has no live order or wallet inputs.
